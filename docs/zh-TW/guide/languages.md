# 支援的語言

ESLint Intl 支援 10 種語言，並且可以輕鬆擴展以支援更多語言。

## 語言列表

### 中文

#### 簡體中文 (Simplified Chinese)

- **代碼**: `zh-CN`
- **使用地區**: 中國大陸、新加坡等
- **特點**: 使用簡化漢字

#### 繁體中文 (Traditional Chinese)

- **代碼**: `zh-TW`
- **使用地區**: 台灣、香港、澳門等
- **特點**: 使用繁體漢字，保留更多歷史字形

### 東亞語言

#### 韓語 (Korean)

- **代碼**: `ko`
- **使用地區**: 韓國、朝鮮
- **特點**: 使用韓文字母

### 歐洲語言

#### 德語 (German)

- **代碼**: `de`
- **使用地區**: 德國、奧地利、瑞士等
- **特點**: 使用複雜的詞彙和語法

#### 法語 (French)

- **代碼**: `fr`
- **使用地區**: 法國、加拿大、比利時等
- **特點**: 詞彙豐富，語法複雜

#### 西班牙語 (Spanish)

- **代碼**: `es`
- **使用地區**: 西班牙、拉丁美洲等
- **特點**: 廣泛使用的語言

#### 俄語 (Russian)

- **代碼**: `ru`
- **使用地區**: 俄羅斯及獨聯體國家
- **特點**: 使用西里爾字母

#### 意大利語 (Italian)

- **代碼**: `it`
- **使用地區**: 意大利、瑞士等
- **特點**: 音韻和諧

#### 葡萄牙語 (Portuguese)

- **代碼**: `pt`
- **使用地區**: 葡萄牙、巴西等
- **特點**: 與西班牙語有相似之處但不同

### 中東語言

#### 阿拉伯語 (Arabic)

- **代碼**: `ar`
- **使用地區**: 中東、北非等
- **特點**: 從右到左書寫，複雜的語法

## 選擇語言

### 透過設定選擇

1. 打開 VS Code 設定 (`Ctrl+,`)
2. 搜尋 `eslintIntl.targetLanguage`
3. 從下拉列表中選擇語言
